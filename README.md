# Amy's Haven Care Home

A mobile-friendly care-home simulator where you play as **Amy, Senior Carer** during a 12-hour UK residential care shift.

> “To care for those who once cared for us is a high honor.”

## What is included

- Playable 07:00–19:00 shift
- Call-bell prioritisation
- Dementia-care decisions
- Toileting and moving/handling scenario
- Medication refusal / MAR scenario
- Falls response
- Confidentiality decision
- End-of-shift documentation and handover
- XP, Safety, Dignity, Wellbeing, Teamwork and Reputation scores
- Resident cards and shift log
- Mobile-friendly layout for iPhone/Safari

## Files

- `index.html` — main game screen
- `styles.css` — design and mobile layout
- `game.js` — game logic, residents, scenarios and scoring

## Put it on GitHub

Upload all three game files to the **root** of your `amys-haven-care-home` repository.

Then enable GitHub Pages:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

GitHub will then give you a public web address for the game.

## Important

This project is a fictional care-home simulation and is not clinical guidance. Real medication, moving/handling, safeguarding and emergency decisions must follow workplace policy and professional guidance.
