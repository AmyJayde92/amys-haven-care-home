# Amy's Haven Care Home — Version 3

This build is the corrected iPhone-first version.

## What changed
- Rebuilt header so it no longer depends on missing image assets.
- Proper Amy's Haven vector-style logo rendered directly in the page.
- Compact iPhone layout with no horizontal overflow.
- Smaller cards, tighter typography and better spacing.
- Seven-item bottom navigation designed to fit a phone screen.
- Replaced most emoji UI with lightweight SVG icons.
- Gameplay flow retained: Start Shift → Handover → Dashboard → Call Bells → Mr Lewis → Mrs Patel → Medication → Personal Care → Care Plan → Schedule.
- Clinical/medication text stays fictional and generic.
