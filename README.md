# Amy's Haven Care Home — Version 2

A mobile-friendly browser care-home simulator for GitHub Pages.

## Play flow
Start Shift → Handover → Dashboard → Call Bells → Mr Lewis / Mrs Patel scenarios → Medication → Personal Care → Care Plan → Schedule.

The supplied visual references are used as in-game background/illustration assets while the interactive controls are real HTML/CSS/JavaScript.

## Safety
This is a fictional simulation. Medication and clinical decisions must follow actual workplace policy, MAR/prescriptions, training and professional guidance.
